SCHOFE STREAM 0.1.0 — QUICK INSTALL

1. Fix/enable SSL for https://schofestream.co.uk in DirectAdmin.
2. Upload the CONTENTS of this folder into the domain's public_html directory.
3. Ensure PHP 8.1+ and PHP cURL are enabled.
4. config.php is already set to:
   https://player.schofestream.co.uk
5. Visit:
   https://schofestream.co.uk/login.php
6. Sign in using an existing Jellyfin user.
7. After login, visit:
   https://schofestream.co.uk/diagnostics.php
8. Test: Home -> movie/series -> Play -> stop -> reopen and confirm resume progress.

Read README.md for troubleshooting and security notes.
